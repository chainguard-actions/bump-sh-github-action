# bump-sh/github-action

Keep your public, private and partner API docs in sync with your code, whether you use OpenAPI or AsyncAPI.


Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/bump-sh/github-action](https://github.com/bump-sh/github-action).
